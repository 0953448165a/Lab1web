## Опис проєкту

У межах лабораторної роботи було налаштовано середовище розробки Visual Studio Code, створено структуру вебпроєкту та розроблено стартову вебсторінку з використанням HTML, CSS і JavaScript.

Також було виконано запуск сторінки через Live Server, дослідження вебсторінки за допомогою DevTools та створено Git-репозиторій для контролю версій проєкту.
